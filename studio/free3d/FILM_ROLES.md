# Film roles → what we have / what is missing (REMAIN CALM)

Sources: crew guides (careersinfilm.com/film-crew, filmlifestyle.com/film-crew-positions, masterclass film-industry-jobs),
animation roles (learn.toonboom.com job-descriptions, toronto.ca animation-roles, awn.com animation-layout),
cinematic-feel articles (nofilmschool.com, uppbeat.io). The sources are thin on performance, subtext and motifs.

| Role | Real job | We have | Missing |
|---|---|---|---|
| Writer | script, beats, dialogue, theme | one-line logline | scene list, beats, lines, what it is *really* about |
| Director | one vision; every shot has a purpose; directs actors | nobody | director's statement, shot purposes, performance notes |
| Producer | schedule, scope, approvals | owner | schedule, pass/fail gates |
| Head of Story / storyboard | script → shots, angles, pacing | storyboard for THE WELL | storyboard + animatic for REMAIN CALM |
| Production designer / art director | look, palette, sets, props, costumes, colour script | PS1 store, cast, line style | locked style sheet, colour script per scene, planted props |
| Character designer | turnarounds, expression sheets | front view only | side/back/3-4 views, expression + pose sheets |
| Layout artist (virtual DP) | camera, lenses, blocking, 180° rule | ad-hoc cameras | shot list, staging plans |
| Animator | acting: anticipation, holds, reactions | idle, bob, squash on fear | acting beats, walk/turn, reaction timing |
| Cinematographer | motivated lighting | flicker, grade | key/fill/rim per scene, motivated light |
| Script supervisor | continuity | nobody | continuity sheet (positions, props, zombie count, time) |
| Editor | rhythm, cut points | nothing yet | animatic, cut plan |
| Sound designer / mixer | room tone, foley, silence before reveals | SFX library, loudnorm | sound plan per shot |
| Composer / music | motif, score | none | theme + stingers |
| Colorist | per-scene grade | one global grade | per-scene grade |
| QC / test viewer | fresh eyes | owner | checklist before render |

Gate order: Writer → Director → Storyboard → Animatic → (owner pass) → Layout → Animation → Light → Sound/Music → Edit → Grade → QC.
We built the art department first and skipped the first four. Do them next.
