## 1) ภาษาภาพ (ทุกฉากต้องมี coverage)
- **Master shot** = ช็อตกว้างบอกที่ + ตำแหน่งทุกคน → **medium** (2–3 คน) → **close-up** (ปฏิกิริยา/ของสำคัญ) · ตัดต่อจากชุดนี้ ไม่ใช่กล้องเดียวเคลื่อนยาว
- **Shot / reverse shot** ตอนสองคนคุยกัน: คนหนึ่งหันซ้าย อีกคนหันขวาเสมอ
- **เส้น 180°**: กล้องอยู่ฝั่งเดียวของแนวสายตา ไม่ข้ามเส้นโดยไม่มีเหตุ (ไม่งั้นตำแหน่งตัวละครสลับด้านจนงง)
- **Cut on action**: ตัดกลางจังหวะเคลื่อนไหว (ยกมือ → ตัดที่มือกำลังยก) ให้รอยต่อมองไม่เห็น
- **Cutaway / insert**: ตัดไปของ/ป้าย/ปฏิกิริยา แล้วกลับมา = มุกภาพและข้อมูลโดยไม่ต้องพูด
- **J-cut / L-cut**: เสียงช็อตถัดไปมาก่อนภาพ (J) หรือเสียงเดิมค้างข้ามภาพ (L) ช่วยซ่อนรอยตัดและต่อเนื่องอารมณ์

## 2) โครงเวลาของคลิปสั้นแนวละครตอนสั้น (60–90 วินาที)
| เวลา | หน้าที่ |
|---|---|
| 0–3 วิ | **ฮุก**: ภาพ/เหตุการณ์ที่ทำให้ถามว่า "เกิดอะไรขึ้น?" ไม่ใช่การอธิบาย |
| 3–30 วิ | เหตุการณ์เริ่ม + ย่อหน้ายกระดับครั้งแรก (mini-climax) |
| 30–55 วิ | **พลิก/เปิดเผย** |
| ท้ายสุด | **cliffhanger = ตัดที่ความตึงสูงสุด** ไม่คลี่คลาย |
- **อัตราตัด 15–25 ตัด ต่อคลิป 75 วินาที** (เฉลี่ย 3–5 วินาที ช่วงฮุก 2–3 วินาที) เร็วกว่าละครทีวีที่ 8–12 วินาที
- ความเครียด/อารมณ์ต้องขึ้นเรื่อยๆ ทุกฉาก ห้ามมีฉากอธิบายล้วน

## 3) การจัดวางและแอ็กติ้งในแอนิเมชัน (staging)
- **ทดสอบเงาดำ**: ถ้าท่าทางอ่านจากเงาไม่ออก = ท่าแย่ ต้องเปลี่ยนมุม/ท่า
- **หนึ่งช็อต หนึ่งการกระทำ** · ใช้ความต่าง (สว่าง/มืด ใหญ่/เล็ก นิ่ง/ขยับ) นำสายตา
- การหันหน้า ระยะห่าง และการยืนข้างกัน/หันหลัง = บอกอารมณ์ (ตึงเครียด/สนิท) โดยไม่ต้องพูด
- **blocking** = วางท่าหลักและเส้นทางเดิน → **staging** = ทำให้ท่านั้นอ่านชัด · เพิ่ม secondary business (เคาะนิ้ว เหลือบมอง) ให้เป็นธรรมชาติ

## 4) เสียง
- ชั้นเสียง: บทพูด → foley (ฝีเท้า ผ้า มือจับของ) → เอฟเฟกต์ → **ambience ต่อเนื่อง** (กันอากาศเปลี่ยนทุกครั้งที่ตัด) → ดนตรี · แยกแทร็ก
- **ดนตรีหลบเสียงพูด (ducking)** · ระดับเริ่มต้นคร่าวๆ: พูดสูงสุด −6 ถึง −3 dB, เอฟเฟกต์ ~−12, ambience −18 ถึง −24, ดนตรี ~−18
- **ความเงียบก่อนเฉลย** สร้างความตึงได้มากกว่าเสียงแน่น · เอฟเฟกต์ใช้พอดี ไม่ใส่ตลอด

## 5) กฎที่ผมจะบังคับใช้กับทุกคลิปใหม่ (ตรวจอัตโนมัติก่อนเรนเดอร์)
1. ไม่มีผู้เล่า · บทพูดอยู่ที่ตัวละคร (+ อุปกรณ์ประกาศของเรื่อง)
2. **ช็อตเฉลี่ย ≤ 3.5 วินาที** และไม่มีช็อตเดียวเกิน 5 วินาที (ยกเว้นเงียบก่อนเฉลย)
3. ทุกฉาก: master → medium → close · สายตา/ทิศทางตัวละครสม่ำเสมอ (เส้น 180°)
4. ทุกบรรทัดพูดต้องมีภาพแอ็กชัน/ของ/ปฏิกิริยา ไม่ใช่ยืนพูดนิ่ง
5. ฮุก 3 วินาทีแรกเป็นภาพ · cliffhanger ท้ายคลิป · การ์ดข้อมูล ≤ 2 ใบ
6. ambience ต่อเนื่องทุกฉาก · J/L-cut ที่รอยตัดหลัก · ความเงียบ ≥ 1 ครั้งก่อนเฉลย
7. ปก/สถานที่/ตัวละครใหม่ทุกหัวข้อ ตามสไตล์ไบเบิลของช่อง
