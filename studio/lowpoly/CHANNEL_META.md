# PosttimeLowPoly — tags / hashtags / description (YouTube only)

## What the reference channel does (vidIQ, 20 top Shorts, 2026-10-31)
- Tags: almost none (19 of 20 videos have no tags; one has "3d animation"). Discovery comes from the recommendation feed, not search.
- Description: 1 paragraph that restates the true story in plain facts (searchable text), asset credits, music credit, then hashtags at the end: `#truestory #shorts #viralshorts #3danimation` (some add `#history`).
- YouTube auto-classifies them as "Video game culture" because of the PS1 look.
- Search demand (vidIQ keyword research, estimates): "low poly shorts" ~416k/mo, "low poly" ~170k, "lowpoly" ~44k, "low poly 3d animation" ~19k (low competition), "low poly art" ~12k (+180%). Blender-tutorial phrases rank high but are the wrong audience: do NOT use them (and we do not use Blender).

## Core tags: put on EVERY clip (13, ~190 chars)
low poly shorts, low poly, lowpoly, low poly 3d animation, ps1 graphics, ps1 style, 3d animation, true story, fun facts, weird facts, did you know, educational shorts, posttime lowpoly
Add 4-6 topic tags per clip (e.g. Pig War: pig war, san juan island, 1859, weird history, history shorts, lyman cutlar). Keep total under 500 characters. Only tags that describe the clip (YouTube penalises misleading tags).
Note: "low poly shorts" is also the name of the reference channel; as a phrase it describes our format and has the highest search volume, so it is included. Remove it if you prefer to avoid any overlap.

## Hashtags in description (first 3 show above the title)
`#shorts #truestory #lowpoly` then optionally `#funfacts #3danimation`. No `#viralshorts` (spammy, no search value). No "AI generated" label (owner rule).

## Description template
1 short paragraph retelling the fact (plain words, keywords: names, places, years) -> blank line -> `Sources: <named sources>` (+ "X is a hypothesis" when it is) -> blank line -> hashtags.

## Title / other
3-7 words, Title Case, deadpan. Category: Education (or Entertainment). Audience: not made for kids. Language: English.

## How to set tags (Buffer cannot)
1. YouTube Studio -> Settings -> Upload defaults: paste the core tags + the default hashtag line once. (Unverified: uploads made through Buffer/the API may NOT inherit these defaults.)
2. Otherwise edit tags per video in Studio after upload (30 seconds each), or vidIQ update_video (5 credits per video; ~17 credits left).
